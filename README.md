# Minimo for iPhone

Android 미니멀 런처 Minimo(MIT, © Vaibhav Lakhera)를 iPhone용 홈 화면 웹앱(PWA)으로 다시 만든 버전.

## 올리기 (택1)
- GitHub Pages: 새 저장소 → 이 폴더의 파일 5개 업로드 → Settings → Pages → Branch: main / root → 저장. 1~2분 뒤 https://아이디.github.io/저장소이름/
- Netlify: 로그인 후 Sites → 이 폴더를 끌어다 놓기

## iPhone 13에 설치
1. Safari로 위 주소 열기 → 공유 → 홈 화면에 추가
2. 홈 화면 아이콘으로 실행 (전체화면)
3. 빈 곳 길게 눌러 설정 → 앱 추가

파일: index.html, manifest.webmanifest, icon-180.png, icon-192.png, icon-512.png
